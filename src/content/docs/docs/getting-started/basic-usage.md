## Six workspace pages

| Key | Page | Purpose |
| --- | --- | --- |
| `1` | Stock | Component records and quantities |
| `2` | Racks | Physical placement and picking |
| `3` | Import | DigiKey orders and KiCad BOMs |
| `4` | Projects | Compare BOM requirements with stock |
| `5` | History | Inspect inventory changes and snapshots |
| `6` | Settings | Workspace, devices, and integrations |

The same destinations are clickable. Use these shortcuts from the normal workspace, outside active text-entry workflows.

## Discover commands

Press `Space` or click **Actions** to see commands available in the current context. Use `Tab` to move focus and `Enter` to activate a control. Use `Escape` to leave an active field, edit, or overlay as appropriate.

Visible actions, keyboard shortcuts, and the action sheet refer to the same workflows. Page-specific guides list shortcuts where they are useful.

## Search and selection

In Stock, type `/` to filter the inventory. Select a result to show its details alongside the list. Use **Sort / Filter**, `f`, or the filters action for sorting and modification-date filtering.

## Terminal size

Keep the terminal at **100 × 30 cells** or larger. If it becomes smaller, Inventatory displays a resize notice instead of a clipped workspace. A wider terminal gives component lists and details more room.
