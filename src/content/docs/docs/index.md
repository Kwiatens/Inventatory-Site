Inventatory combines a Windows terminal application with an optional, dedicated handheld scanner. The desktop application owns your local inventory, rack locations, projects, and history.

## Start here

1. [Install on Windows](getting-started/installation/).
2. [Create your first inventory](getting-started/first-inventory/).
3. [Learn navigation and controls](getting-started/basic-usage/).

You can use the application without a scanner. DigiKey metadata enrichment, printers, and Scan R1 are separate setup choices.

| What you want to do | Guide |

## Documentation scope

These guides were checked against application source on 22 September 2026. They describe the current source; controls and workflows can differ in older releases. The verified download is **v0.2.0-rc.2**, a prerelease. Consult the [release notes](https://github.com/Kwiatens/Inventatory-Software/releases/tag/v0.2.0-rc.2) for your installed version.

The software is Windows-only and in public beta. Scanner hardware and firmware distribution have not been publicly verified; read the [hardware status](scanner/status/) before planning a build or purchase.
