## Verified desktop support

The inspected Windows application contains Scan R1 setup, physically verified Bluetooth LE provisioning, local-network discovery, an authenticated device synchronization service, inventory-event handling, component lookup, quick-label integration, and visible device status.

## Public distribution is unresolved

On **22 September 2026**, the public GitHub API did not expose the hardware repository referenced by the desktop build configuration. This does not establish whether it is private, renamed, or unavailable.

The following have not been verified for publication:

- Public hardware revision and availability.
- A released, compatible firmware image and its update instructions.
- Assembly files, bill of materials, and build instructions.
- Scanner specifications such as battery life or supported scan formats.
- An authentic hardware photograph and demonstration video.
- A complete on-device scanning and quantity-operation walkthrough.

There is no purchase, firmware-download, or assembly link on this site until an authoritative public resource is available.

## Naming

Older repository prose uses **Inventascan**. These guides use **Inventatory Scan R1**, matching the current desktop setup and transport documentation.

## Using the desktop today

You do not need scanner hardware to manage stock, racks, imports, projects, or history. Start with [installation](../../getting-started/installation/) and add a compatible scanner later.
